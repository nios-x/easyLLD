How to work each problem
Requirements (5 min): write 5–7 bullets, plus what is out of scope.
Entities and class diagram (15 min).
Code (60–75 min): models, then interfaces, then services, then the driver.
Compare with a reference solution only after you finish. Use the awesome-LLD repo or kousiknath/LowLevelDesign. Write down 3 things they did better in a mistakes.md file.
Extension test: add one new requirement, such as a new vehicle type or split type. If you had to edit more than 2 classes, your design was too rigid, so refactor it.
